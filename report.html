Лабораторная работа № 2

Макет CSS Grid

Выполнил(а) _________________________ · Группа __________

Цель

Создать адаптивный макет из шапки, бокового меню, основного содержимого и подвала.

Ход работы

Layout размещает четыре области через grid-template-areas. Header выравнивает заголовок и приветствие с помощью Flexbox. Sidebar получает пункты меню через props, а MainContent выводит переданный через children фрагмент JSX.

Переключатель показывает три схемы Grid: меню слева, меню справа и пустая колонка между содержимым и меню. CSS-переменные задают цвета и расстояния между областями. При ширине до 768 px блоки располагаются вертикально.

Результат проверки

В браузере проверено переключение на макет с пустой колонкой. При ширине 390 px боковое меню располагается ниже основного блока.

Воспроизведение

Распакуйте архив, выполните npm.cmd ci и npm.cmd run dev из папки с package.json. Откройте адрес, указанный Vite в терминале. Выберите «С пустой колонкой», затем измените ширину окна. Ссылки меню ведут к разделам основного блока.
